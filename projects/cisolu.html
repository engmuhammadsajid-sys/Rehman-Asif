Cisolu — SaaS Portal

  • Live URL: cisolu.com
  • Tech Stack: Next.js, Node.js, MongoDB, Tailwind CSS, Stripe, RAG / AI

Full-stack SaaS web application with server-side rendering, secure authentication, protected routes, and role-based access control for candidates and companies.

Built AI features including RAG (Retrieval-Augmented Generation) integrations for intelligent document/context-aware responses and assistant workflows.

Integrated Stripe payment gateway for subscriptions and monetization, delivering a production-ready SaaS product from development through deployment.
