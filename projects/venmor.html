Venmor — Watch E-Commerce

  • Live URL: venmor.in
  • Tech Stack: MERN Stack, Stripe, Cloudinary, Shopify integrations, MCP Server, JWT

Full-stack e-commerce platform for a premium watch brand featuring product management, secure checkout, order tracking, and a role-based admin dashboard.

Implemented Shopify integrations alongside Stripe payments and Cloudinary media management for a smooth catalog and checkout experience.

Built MCP server automation (including AI-assisted PR review workflows) to speed up development and improve code quality across the project.
